# Superstore Sales Data Analytics Dashboard

## 📊 Project Overview

This project presents an end-to-end **Sales Data Analytics and Dashboard** built using Microsoft Excel and the Superstore dataset.

The objective of this project is to transform raw sales data into meaningful business insights by performing **data cleaning, exploratory analysis, KPI analysis, and interactive dashboard creation**.

The project focuses on understanding sales, profit, customers, products, categories, regions, states, discounts, and time-based performance.

---

## 🎯 Business Objective

The main objective is to answer important business questions such as:

* What are the overall Sales, Profit, Orders, and Customers?
* How do Sales and Profit change over time?
* Which Product Categories contribute most to Sales and Profit?
* Which Sub-Categories are most and least profitable?
* Which Regions perform strongly in terms of Sales and Profit?
* Which Customer Segments generate the most Sales?
* Which Products are the top contributors to Sales?
* Which Products or Sub-Categories generate losses?
* How does Discount affect Profitability?
* Which States demonstrate strong and weak Sales performance?

## 🧹 Data Preparation

The raw Superstore dataset was reviewed and prepared before analysis.

The data preparation process included:

* Checking the dataset structure
* Identifying and handling duplicate records where applicable
* Checking missing values
* Reviewing data types
* Validating important fields
* Preparing a clean dataset for analysis
* Using the cleaned data as the foundation for the dashboard

The cleaned dataset contains **9,994 records** and **21 columns**.

Analysis of Sales and Profit generated by different Customer Segments.
